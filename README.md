# MariaDB Foundation hackathons

The MariaDB Foundation arranges hackathons, and hosts challenges at other hackathons, to help people adopt MariaDB
and contribute to it. Projects usually fall into two tracks:

- **Integration:** make MariaDB easy to use in every tool, language and environment.
- **Innovation:** build feature demos and use cases that others can learn from and adapt.

A full list of the hackathons the MariaDB Foundation has taken part in, with their blogs and winners, is at
[mariadb.org/hackathons](https://mariadb.org/hackathons). To organise one with us, write to
[hackathon@mariadb.org](mailto:hackathon@mariadb.org).

## Hackathon resources

### Junction 2026

At [Junction 2026](https://2026.hackjunction.com/) in Espoo, Finland, on 13–15 November 2026, the MariaDB Foundation
hosted **MariaDB's Wikipedia challenge**: build the tools Wikipedia is missing, using MariaDB Vector, system-versioned
tables, or both. 36 teams submitted a project. The winners were:

1. **Janus**, by Saunan Pojat ([code](https://github.com/ayaanjamil/janus))
2. **Language Mirror**, by Bob the Builders ([code](https://github.com/silvekoski/languagemirror))
3. **Ghosts of Wikipedia**, by Chrysalis ([code](https://github.com/salomeshioshvili/ghosts_of_wikipedia))

- **All submissions:** [junction-2026](junction-2026/), with links to code and public videos, and a CSV of how each
  project uses MariaDB.
- **Starting points:** [mariadb-wikipedia-datasets](https://github.com/MariaDB/mariadb-wikipedia-datasets),
  [mariadb-vector-wikipedia-rag](https://github.com/MariaDB/mariadb-vector-wikipedia-rag) and
  [mariadb-system-versioning-wikipedia](https://github.com/MariaDB/mariadb-system-versioning-wikipedia).
- **Blog:** [MariaDB's Junction 2026 challenge in numbers](https://mariadb.org/junction-2026/)
